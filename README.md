# ShadowFox Data Analyst Project

## 📌 Project Overview
This project was completed as part of the ShadowFox Data Analyst Internship.

The project focuses on analyzing sales data using Microsoft Excel to identify sales trends, category performance, branch performance, and key business insights.

## 🎯 Objective
- Clean and organize the sales dataset
- Analyze sales and transaction performance
- Identify monthly and category-wise trends
- Compare branch performance
- Create charts and a simple dashboard
- Generate useful business insights

## 🛠️ Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Data Cleaning
- Dashboard & Data Visualization

## 🧹 Data Cleaning
The dataset was checked for:
- Duplicate records
- Blank values
- Incorrect date formats
- Unnecessary blank categories

The cleaned data was then used for analysis.

## 📊 Analysis Performed
The project includes:
- Product Line Sales Analysis
- Monthly Sales Trend Analysis
- Branch-wise Sales Analysis
- Total Sales
- Total Transactions
- Total Quantity
- Average Sales

## 📈 Dashboard
An Excel dashboard was created to present the key metrics and visual insights in an easy-to-understand format.

## 💡 Key Insights
- Food & Beverages had the highest sales among product lines.
- Health & Beauty had the lowest sales.
- Giza recorded the highest branch sales.
- Alex recorded comparatively lower sales.
- Monthly sales trends were analyzed to identify high and low performing periods.

## 📌 Conclusion
The analysis helps identify strong-performing product categories and branches while highlighting areas that may require improvement.

This project helped demonstrate practical skills in data cleaning, Excel analysis, visualization, and business reporting.
